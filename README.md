# Birthday Reminder

This module adds a Birthday field to the Partner (Customer/Vendor) form and sends automatic reminders when a partner's birthday arrives.

## Features
- Adds a Birthday date field to res.partner.
- Automatically checks daily if any partner has a birthday.
- Can be extended to send emails, pop-up notifications, or other reminders.

## Installation
1. Download or clone this module into your Odoo `addons` directory.
2. Update the Apps list.
3. Search for **Birthday Reminder** and install it.

## Usage
- Go to Contacts ➔ Customers/Vendors.
- Edit a contact and set their Birthday.
- The system will automatically check daily for birthdays.
- You can customize the reminder logic as needed.

## Compatibility
- Odoo Version: 16.0
